QuickFlows User Guide

Launch your multi-link workflows instantly using customizable keyboard shortcuts.

⚡ Step 0: Set Up Main Key Listener Shortcut First!

Before creating any custom workflows, you must set up the main key listener command in Chrome:

  1. Open chrome://extensions/shortcuts in your Chrome address bar.
  2. Locate QuickFlows in the list.
  3. Assign a shortcut key to Trigger keybinds (recommended: Ctrl+Shift+0).
  4. Once set, you're ready to create your workflows below!
Trigger Shortcut: Press Ctrl+Shift+0 on any webpage to activate the key listener popup, then press your custom keybind to launch your workflow!

1. How Shortcuts Work

QuickFlows provides two types of shortcuts:

  • Trigger Keybind Listener (Ctrl+Shift+0): Activates key listening on the active webpage. Once activated, press any custom keybind (e.g. ctrl+shift+a). Press Esc to cancel key listening.
  • Default Shortcuts (Ctrl+Shift+1, Ctrl+Shift+2, Ctrl+Shift+3): Global Chrome shortcuts that launch a workflow instantly from anywhere in Chrome without pressing Ctrl+Shift+0 first!

2. Creating & Configuring Workflows

  • Add Title: A descriptive name for your workflow (e.g., "Morning Work Routine").
  • Add Keybind: Click the input field and press your desired key combination (e.g. ctrl+shift+a or ctrl+shift+space). Press Backspace or Esc to clear the input field.
  • Set Up Default Workflow: Select one of the built-in Chrome commands (ctrl+shift+1, ctrl+shift+2, ctrl+shift+3) to bind it directly to a global shortcut.
  • Add Delay: Optional delay in milliseconds between opening tabs (useful for heavy websites or rate-limited APIs).
  • Incognito Mode: Opens all links in a private browser window. (Requires "Allow in incognito" to be enabled in Chrome extension settings).
  • Run in New Window: Opens all links together in a clean new browser window instead of current tab.
  • Links: Enter one URL per line (e.g., https://github.com or youtube.com). QuickFlows automatically adds https:// if a scheme is omitted.

3. Important Limitations & Tips

⚠️ Webpages vs Restricted Chrome Pages:
Due to Chrome security restrictions, the page key listener (Ctrl+Shift+0) only runs on regular web pages (e.g., https://...). It cannot be activated on restricted pages such as chrome://, chrome-extension://, Chrome Web Store, or blank New Tab pages.

Tip: If you want a workflow to work anywhere (including New Tab pages), assign it as a Default Workflow (Ctrl+Shift+1, Ctrl+Shift+2, or Ctrl+Shift+3)!
🕵️ Incognito Mode Setup:
To allow workflows to open in Incognito mode, go to chrome://extensions, click Details on QuickFlows, and enable Allow in incognito.

4. Quick Access Popup

Click the QuickFlows icon in your Chrome toolbar at any time to open a quick view popup. From the popup, you can view your workflows and click any link directly to open it in a new tab.
