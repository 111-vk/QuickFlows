QuickFlows User Guide

QuickFlows lets you launch multi-link workflows instantly using customizable keyboard shortcuts.

0. Initial Setup

Important: Before creating workflows, you must set up the key listener keybind:

  1. Go to chrome://extensions/shortcuts in your Chrome address bar.
  2. Find QuickFlows in the list.
  3. Set the Key Listener command to your desired shortcut (default: Ctrl+Shift+0).
  4. Now you're ready to create workflows!
Trigger Shortcut: Press Ctrl+Shift+0 on any webpage to activate the key listener popup, then press your saved workflow keybind!

1. Creating a Workflow

  • Title: Enter a friendly name for your workflow (e.g., "Morning Work").
  • Keybind: Focus the keybind input and press your desired shortcut (e.g. ctrl+shift+a or ctrl+shift+space). ⚠️ Avoid using existing browser shortcuts like ctrl+a, ctrl+t, ctrl+n, ctrl+w, etc. — they may conflict with Chrome's native commands.
  • Default Workflows: Select a built-in browser shortcut (ctrl+shift+1, ctrl+shift+2, ctrl+shift+3) from the dropdown to trigger the workflow without pressing Ctrl+Shift+0 first!
  • Delay: Specify optional delay in milliseconds between opening tabs.
  • Incognito Mode: Check to launch links in a private browser window.
  • Run in New Window: Check to open all links in a fresh browser window.
  • Links: Enter full URLs or domain names separated by new lines (e.g., https://github.com or youtube.com).

2. Triggering Workflows

There are two ways to trigger your saved workflows:

  • Page Shortcut Listener: Press Ctrl+Shift+0 to activate key listener, then type your workflow's custom keybind (e.g. ctrl+shift+a). Press Esc to cancel key listening.
  • Default Shortcuts: Workflows configured with default shortcuts (ctrl+shift+1, ctrl+shift+2, ctrl+shift+3) can be pressed anywhere in Chrome at any time! You can customize these shortcuts in Chrome's native page at chrome://extensions/shortcuts.

3. Tips & Tricks

  • If no protocol (like https://) is provided for a URL, QuickFlows automatically adds https:// for you.
  • To delete a workflow, click the X button on the top right of its card in the dashboard.
